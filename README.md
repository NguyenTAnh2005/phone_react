# Phone Selling Website (React + Tailwind CSS)

🇻🇳 Vietnamese version: [README_VI.md](./README_VI.md)

A basic React project developed to practice core React concepts and improve frontend skills.  
The application simulates a used phone selling website.

---

## ⏳ Development Timeline

- **Developed during:** Semester 1 – Year 3  
- **Purpose:** Learning & practicing React fundamentals  
- **Technologies:** React, Tailwind CSS  
- **Project Type:** Personal Learning Project  

---

## 📌 Project Overview

This project was built as a practice exercise while learning React.  

The goal was to become familiar with:
- Component structure
- Props & state
- Basic state management
- Rendering lists
- Simple UI layout with Tailwind CSS

The application simulates an online store for selling used phones, similar in concept to my ASP.NET MVC project. However, this version focuses primarily on frontend practice.

---

## 🚀 Key Features

- Display phone products

- Component-based structure
- Simple state handling
- Practice-level React project structure

## ⚠ Project Status

This project was discontinued.

After experimenting with React, I decided to rebuild the used phone selling system using **ASP.NET MVC (C#)** because:

- I was more comfortable with C#
- Development felt faster and more structured
- Backend + frontend integration was easier for me at that time

This React project reflects my early learning stage with the framework.
