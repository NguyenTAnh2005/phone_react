# Website Bán Điện Thoại Cũ (React + Tailwind CSS)

Ứng dụng web được xây dựng bằng React và Tailwind CSS nhằm mục đích học tập và làm quen với React cơ bản.  
Dự án mô phỏng một website bán điện thoại cũ.

---

## ⏳ Thời gian thực hiện

- **Thực hiện vào:** Học kỳ 1 – Năm 3  
- **Mục đích:** Học và thực hành React cơ bản  
- **Công nghệ:** React, Tailwind CSS  
- **Loại dự án:** Dự án tự học  

---

## 📌 Tổng quan dự án

Đây là dự án được thực hiện trong quá trình học React nhằm làm quen với:

- Cấu trúc component
- Props và State
- Quản lý trạng thái cơ bản
- Render danh sách dữ liệu
- Thiết kế giao diện bằng Tailwind CSS

Website mô phỏng hệ thống bán điện thoại cũ, tương tự ý tưởng với dự án ASP.NET MVC của tôi. Tuy nhiên, phiên bản này chủ yếu tập trung vào frontend và thực hành React.

---

## 🚀 Chức năng chính

- Hiển thị danh sách sản phẩm điện thoại
- Giao diện xây dựng bằng Tailwind CSS
- Cấu trúc theo hướng component
- Xử lý state cơ bản
- Dự án ở mức độ luyện tập React

---

## 🛠 Công nghệ sử dụng

- **React (Functional Components)**
- **Tailwind CSS**
- **JavaScript (ES6+)**
- **Vite / Create React App** (tùy cấu hình bạn đã sử dụng)

---

## 🧠 Những gì tôi học được

Thông qua dự án này, tôi đã:

- Làm quen với cách xây dựng giao diện bằng React
- Hiểu cơ chế hoạt động của state và props
- Thực hành render dữ liệu động
- Cải thiện kỹ năng CSS với Tailwind
- So sánh cách xây dựng frontend giữa React và ASP.NET MVC

---

## ⚠ Trạng thái dự án

Dự án đã dừng phát triển.

Sau khi thực hành với React, tôi quyết định chuyển sang xây dựng lại hệ thống bằng **ASP.NET MVC (C#)** vì:

- Tôi quen thuộc với C# hơn
- Quá trình phát triển nhanh và dễ kiểm soát hơn
- Việc tích hợp backend và frontend thuận tiện hơn tại thời điểm đó

Dự án này phản ánh giai đoạn đầu trong quá trình học React của tôi.

---

- Dự án tập trung vào mục đích học tập
- Chưa tối ưu về kiến trúc và hiệu suất
- Kiến thức React ở thời điểm thực hiện còn ở mức cơ bản
